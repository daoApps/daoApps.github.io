# 变现闭环 · 第三方入驻设计

> 从"自己卖工具"到"平台+第三方"的扩展设计

---

## 一、为什么要第三方入驻？

```mermaid
flowchart TD
    A["自己卖工具<br/>学习体检9.9元"] -->|"瓶颈"| B["品类有限<br/>只有学习类"]
    B --> C["增长天花板低<br/>只能服务自己能做的"]
    C --> D["需要更多品类<br/>更多好东西"]
    D --> E["第三方入驻<br/>平台提供信任和流量"]
```

**核心逻辑**：道德大师兄做的是"信任入口"——用户信任这个品牌，所以愿意通过这个平台发现好东西。平台不需要自己生产所有内容，只需要保证"经过大师兄筛选的，都是靠谱的"。

---

## 二、谁可以入驻？

```mermaid
flowchart LR
    subgraph 入驻者类型
        T1["独立创作者<br/>写文章/做课程/出工具"]
        T2["小工作室<br/>有产品但缺流量"]
        T3["结伴频道里的人<br/>已经在群里分享过真东西"]
    end

    subgraph 准入条件
        Q1["作品真实<br/>自己真用过真做过"]
        Q2["不割韭菜<br/>不做收费导流"]
        Q3["有真案例<br/>不是凭空编的"]
        Q4["价格合理<br/>不是暴利产品"]
    end

    T1 --> Q1
    T2 --> Q2
    T3 --> Q3
    Q3 --> Q4
```

**最优先的入驻者：结伴频道里已经在分享的人。**
- 愈多·业频道里分享AI案例的人 → 可以做AI工具指南
- 知和·家频道里分享婚姻经验的人 → 可以做婚姻经营手册
- 恒与·伴频道里认识朋友的人 → 可以做认识朋友的方法论

这和品牌定位完全一致：**已经在群里分享真东西的人，把他们的分享产品化。**

## 三、卖什么？（品类边界）

```mermaid
flowchart TD
    Platform["平台允许的品类"]

    Platform --> C1["工具类<br/>学习体检/习惯打卡/指南手册"]
    Platform --> C2["内容类<br/>专题文章/深度报告/手册"]
    Platform --> C3["服务类<br/>1v1咨询/小组陪伴"]

    Platform -.->|"禁止"| B1["课程类<br/>训练营/大课"]
    Platform -.->|"禁止"| B2["会员制<br/>年费制/订阅制"]
    Platform -.->|"禁止"| B3["金融类<br/>投资/理财/带单"]
```

**品类红线：**
- ✅ 工具：一次性付费，用一次算一次
- ✅ 内容：一次性付费，买一份算一份
- ✅ 服务：按次付费，不做长期套餐
- ❌ 课程：训练营/大课/系列课——这是割韭菜重灾区
- ❌ 会员：年费/订阅制——这是持续收割
- ❌ 金融：投资/理财/带单——这是杀猪盘重灾区

## 四、平台怎么赚钱？

```mermaid
flowchart LR
    A["第三方产品售价"] --> B["平台抽成"]
    A --> C["第三方收入"]

    B --> D["抽成比例<br/>10%-20%"]
    C --> E["创作者拿大头<br/>80%-90%"]

    D --> F["平台收入<br/>用于维护和运营"]
```

**抽成原则：**
- 创作者拿大头（80-90%），平台拿小头（10-20%）
- 不是平台赚差价，是平台收"信任费"和"流量费"
- 价格由创作者定，平台不干预，但要审核价格合理性

---

## 五、怎么保证质量？

```mermaid
flowchart TD
    A["入驻申请"] --> B["人工审核"]
    B --> C{"审核通过？"}
    C -->|"通过"| D["上线展示"]
    C -->|"不通过"| E["拒绝并说明原因"]

    D --> F["用户购买"]
    F --> G{"用户评价"}
    G -->|"好评"| H["继续展示"]
    G -->|"差评"| I{"差评过多？"}
    I -->|"是"| J["下架整改"]
    I -->|"否"| H
```

**三道质量门：**
1. **入驻审核**：大师兄人工审核，看作品是否真实、是否符合品牌调性
2. **上线后监控**：用户评价机制，差评多了就下架
3. **定期复审**：定期检查入驻者的产品是否还符合标准

## 六、和三环闭环的关系

```mermaid
flowchart LR
    A["结伴闭环（人）<br/>微信群 + 沉淀墙"] -->|"产生好内容"| B["学习闭环（学）<br/>体检 + 练习"]
    B -->|"发现好工具/好内容"| C["变现闭环（钱）<br/>自己卖 + 第三方入驻"]
    C -->|"收入反哺"| A
```

**第三方入驻在三环里的位置：**
- 结伴闭环产生好内容（群里的人分享真东西）
- 学习闭环验证这些内容有效（体检→练习→复评）
- 变现闭环把这些内容产品化（自己做的 + 第三方做的）

## 七、第一阶段：先从身边人开始

```mermaid
flowchart LR
    Phase1["第一阶段<br/>身边人"] --> P1["愈多频道分享AI案例的人<br/>出一份AI工具指南"]
    Phase1 --> P2["知和频道分享婚姻经验的人<br/>出一份婚姻经营手册"]
    Phase1 --> P3["大师兄自己<br/>学习体检深度报告"]

    Phase2["第二阶段<br/>扩展到外部"] --> Q1["邀请其他独立创作者入驻"]
    Phase2 --> Q2["开放申请入口"]
```

**不要一上来就开放平台。先从结伴频道里已经在分享的人开始，验证模式跑通了再扩展。**

## 八、红线总结

| # | 红线 | 原因 |
|---|------|------|
| 1 | 不卖课程、不做训练营 | 割韭菜重灾区 |
| 2 | 不卖会员、不做订阅制 | 持续收割模式 |
| 3 | 不做金融、不做投资带单 | 杀猪盘重灾区 |
| 4 | 第三方必须人工审核 | 不是开放平台，是精选平台 |
| 5 | 差评多了必须下架 | 信任是核心资产 |
| 6 | 创作者拿大头 | 平台不是赚差价，是收信任费 |
