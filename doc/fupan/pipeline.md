### 关键判断 1：四级分层是这次最有价值的设计

传统做法是「事实 / 作者观点」两层。本次加了 **D 级（本包推断）**，并配一条硬纪律：

> **D 级内容在正文中一律以「本包推断」「可推导」等措辞呈现，不得写成人物原话或史实。**

**实际效果**（复盘发现）：

- 陶行知包的「四大精神四层结构」是**搜狐作者的归纳，不是陶行知原话** —— 分层后必须在正文显式声明「该归纳为该文作者所加的结构化整理」；
- 游本昌的「每集 120 元」「基金会 165.66 万人次」等数据全部落在 C 级，且在正文加警示「未取得官方独立印证」；
- 胡歌的「如果外表无法复原，那就用思想去填满它吧」虽广为流传，但无 A 级信源 —— **降级为「特定处境下的自我对话」，不作为可普遍引用的原则**。

**如果只做两层分层，这三处都会在成文时混进「事实」层。**

### 关键判断 2：伪事实在成文前被拦下

采集过程中发现三条无法取得一手出处的信息，**全部标记为 D 级待核并隔离**：

| 编号 | 内容 | 处置 |
|---|---|---|
| F-TX-079 | 陶行知与胡适讨论中文语法 | 标记待核，**正文不引用** |
| F-YB-099 | 游本昌 2024 年携孙女捐图书细节 | 降级 D 级，**正文不引用** |
| F-HG-033 | 「用思想填满」的原始出处 | 降级为「特定处境下的自我对话」 |

> **复盘结论**：`采集 → 分层 → 成文` 这个顺序里，**分层必须在成文之前**。否则一旦写完，再回头标注「这条其实是推断」，等于承认前面的分层是摆设。

### 关键判断 3：游本昌的时点改变了教程定位

采集到第一条事实就是：**游本昌于 2026 年 9 月 24 日凌晨离世，享年 93 岁**；9 月 30 日告别仪式在八宝山举行；女儿游思涵对外表示他最后一句话是「我很舒服」。

> **这改变了教程的定位**（推断）：不是「人物介绍」，而是「身后回望式的方法论萃取」。
>
> 三个具体后果：
> 1. 根 index 置顶加**时点声明**：「任何涉及其生平的表述以 2026-09-24 为终止界」；
> 2. `stale_after` 设为 **2027-10-03**（遗产分配、纪念活动属强时效内容）；
> 3. 新增一篇 concepts「边界与禁区」，专列**五种身后叙事的误读风险**（神人化 / 成就归因单一化 / 道德完美化 / 成果不可核查化 / 情绪化继承）。

## 二 · I 阶段：洞察（三条核心洞察 × 四包）

**执行方式**：每个包从 R 阶段事实中提炼 3 条四元组洞察（陈述 + 证据 F 编号 + 反常识 + 行动）。

### 各包的洞察清单

| 包 | 洞察 1 | 洞察 2 | 洞察 3 |
|---|---|---|---|
| **陶行知** | 最可迁移的不是教育理论，是**自我要求的强度**（四问对所有人同用） | **六大解放不能自授，只能检测**（裹头布是环境给你裹的） | **不可测量的东西不要给方法论**（道德问无配套方法是刻意的） |
| **游本昌** | **「不能爱艺术中的自己」是一条可跨领域复用的护栏** | **用不划算的规则换取更值钱的东西**（一集一元 / 卖房拍弘一 / 学堂退费） | **「种子计划」是最可迁移的机制**（不派人驻村，先培养能去的人） |
| **胡歌** | **反馈延迟是能力杀手**（选失败成本真实的环境） | **持续在场是护城河**（外部变量最小，规模是副产品） | **不要伪造因果，也不要消费创伤** |
| **关联包** | 真正共通的不是「努力/善良/坚持」，是**四条机制** | 只有游本昌与胡歌有真实人际关联，**陶行知是精神同向** | 胡歌与游本昌的公益是**同向而非因果**（早 12 年） |

> **复盘发现的高价值洞察**：胡歌包的洞察 1（**反馈延迟**）与洞察 2（**护城河**）是**从事实中推出来的，不是从金句中摘的**。
>
> 具体路径：
> ```
> 事实：电视剧可剪辑（F-HG-009/054/055）vs 环形舞台不可 NG（F-HG-052）
>      → 差异不是「话剧更能磨演技」
>      → 差异是「反馈延迟」：数月 vs 当场
>      → 推论：人对延迟反馈的响应是衰减的
>      → 洞察：延迟是能力杀手
> ```
>
> **这条链有四步，每步都可回溯**。对比「他很努力所以他成功」这种洞察 —— 无证据、不可迁移、不可检验。

## 三 · F 阶段：第一性原理（公理提炼 + 三个框架）

**执行方式**：从 I 阶段洞察继续追问到不可再分的基础单元，提炼自洽公理，再自下而上重构。

### 各包提炼的公理

| 包 | 公理 |
|---|---|
| 陶行知 | ① 前提核验是移植方法论的第一道工序 ② 六大解放是诊断表不是方法论（裹头布只能由环境解） ③ 不可测量的不给方法论 |
| 游本昌 | ① 复利的前提是积累质量一致 ② 长期导向需要护栏，否则会转成地位维护 ③ 「我走了之后还在吗」是投入与消费的唯一区别 |
| 胡歌 | ① 事件的破坏力取决于它损毁了什么资本 ② 人对延迟反馈的响应是衰减的 ③ 护城河 = 退出成本 ④ 两条独立路径相遇是互相确认而非单向传授 |

### 关联包的三个框架（用户指定的三个角度）

三个框架不是并列的，而是**分层互补**的：

```
框架三：正面解读师  （方法层）—— 怎么读榜样，不滑向吹捧
            ↓ 约束
框架一：真问题·真需求·真目标（诊断层）—— 我在哪
框架二：品质·技能·身份        （能力层）—— 我缺什么
            ↓ 输入
五阶段学习路径（行动层）—— 怎么开始
```

| 框架 | 层 | 解决的问题 | 核心工具 |
|---|---|---|---|
| **真问题·真需求·真目标** | 诊断 | 我是不是在解决一个假问题 | 三层定义 + 六判据 + 五步工作表 |
| **品质·技能·身份** | 能力 | 我该补哪一层 | 三层判据 + 顺序不可颠倒的三条论证 + 三步自检 |
| **正面解读师** | 方法 | 怎么正面解读而不吹捧 | 六步骤 + 归因克制四规则 + 三类拒绝话术 + 三个虚构反面教材 |

> **复盘发现的设计要点**（推断）：
>
> 三个框架各自配了**可填写的表格**（五步工作表 / 三步自检 / 解读工作表），而不是只给概念。
>
> 原因：「品质技能身份」这样的三元模型很容易变成「正确的废话」。**加一个必须填的表格，它就有了判定标准** —— 比如框架二的完成标准是「技能清单里至少一项有实际验证」，没验证就说明本框架不适用。

### F 之后的 V 是强制的

按方法论规范，**F 之后必须 V**，理由是：第一性原理推导出的方案天然缺乏历史校验。

本次 V 阶段确实拦下了实质问题（见下页）。

## 八 · 门禁实测（关键记录）

**这一节是本次复盘最可复制的部分。**

### 官方三道门禁（实际运行，非手动等效替代）

```
$ python scripts/check-utf8.py
UTF-8 检查通过: 10797 个文件均为有效 UTF-8。

$ python scripts/check-bundles-index.py
bundles 总索引对账通过: 9 域 / 60 组 / 582 束，
frontmatter、计数行、节标题、分组表、toctree 五面一致。

$ python scripts/check-toctrees.py
检测到 11 处 toctree 导航问题，CI gate 拦截：
  - 未收录(不可达): ...taoxingzhi-youbenchang-huge/concepts/00-common-mechanisms.md
  - 未收录(不可达): ...taoxingzhi-youbenchang-huge/concepts/01-evidence-bridges.md
  ... 共 11 条
```

**根因**：关联枢纽包的根 `index.md` 漏写了 `toctree` 块。其余三个包都写了，只有这一个漏了。

**修复**：在根 index 末尾补上：

````
```{toctree}
:hidden:
:maxdepth: 7

concepts/index
references/index
log
```
````

**复跑**：

```
$ python scripts/check-toctrees.py
toctree 检查通过: 全部 index.md 引用有效，所有内容文档均可达。
```

### 为什么这次拦截很关键

Sphinx 对**不在任何 toctree 中的文档**的处理是：**不生成页面，且不报错**（除非用 `-W` 且该文档被其他文档 `toctree` 到）。

> 也就是说：如果没跑这个门禁，那 11 个文件会**静默地留在导航之外** —— 文件存在、能用编辑器打开，但站点上没有任何入口能到达它们。
>
> **「已完成」这个词在那一刻是主观判断；门禁把它变成了机器判定。**
